# 📌 Migración de LibreOffice para conversión en servidor ARM (t4g.medium)

Este documento resume **todo lo realizado hasta ahora**, paso a paso, en **formato Markdown plano NO interpretado**, para documentar la instalación de LibreOffice en el nuevo servidor ARM y validar la conversión manual antes de integrar Flask y systemd.

---

## 🖥️ 1. Contexto de la migración

- Servidor anterior: **EC2 t3.medium (x86_64)**
- Nuevo servidor: **EC2 t4g.medium (ARM64 / Graviton)**
- Objetivo: migrar LibreOffice + API Flask de conversión usada por n8n
- Ruta donde se necesita LibreOffice: `/opt/libreoffice25.8/`
- Conversión de archivos usada por n8n: `/home/ec2-user/n8n_files/conversions/`
- Python versión requerida: `Python 3.11`
- Flask ya está instalado en el nuevo servidor (confirmado)

---

## 📂 2. Descarga e instalación de LibreOffice ARM

```
cd /opt
sudo wget https://download.documentfoundation.org/libreoffice/stable/25.8.2/rpm/aarch64/LibreOffice_25.8.2_Linux_aarch64_rpm.tar.gz
sudo tar -xvzf LibreOffice_25.8.2_Linux_aarch64_rpm.tar.gz
cd LibreOffice_25.8.2.2_Linux_aarch64_rpm/RPMS
sudo dnf install -y *.rpm
```

---

## 🧩 3. Instalación de dependencias faltantes (errores resueltos)

Durante la ejecución de `soffice --version`, el sistema reportó librerías faltantes. Se resolvieron con:

```
sudo dnf install -y libXinerama libXrandr libXrender libSM libXext libICE
sudo dnf install -y libxslt
sudo dnf install -y libX11-xcb
```

Dependencias opcionales que pueden ser necesarias en otras instalaciones:

```
sudo dnf install -y fontconfig libxcb
```

---

## ✅ 4. Verificación final de LibreOffice

```
/opt/libreoffice25.8/program/soffice --version
```

Salida correcta obtenida:

```
LibreOffice 25.8.2.2  a4401f2107ccab8f924a8e2df40f5733aab7605b6f
```

---

## 📁 5. Creación de carpetas para n8n (archivos + conversiones)

```
sudo mkdir -p /home/ec2-user/n8n_files
sudo mkdir -p /home/ec2-user/n8n_files/conversions
sudo chown -R ec2-user:ec2-user /home/ec2-user/n8n_files
```

---

## 🧪 6. Prueba manual de conversión (ANTES de Flask)

Crear archivo de prueba:

```
echo "Prueba LibreOffice" > /home/ec2-user/n8n_files/test.txt
```

Ejecutar conversión manual:

```
/opt/libreoffice25.8/program/soffice --headless \
 --convert-to pdf \
 --outdir /home/ec2-user/n8n_files/conversions \
 /home/ec2-user/n8n_files/test.txt
```

Verificar archivo generado:

```
ls -l /home/ec2-user/n8n_files/conversions
```

Resultado esperado:

```
-rw-r--r--  test.pdf  ✅
```
